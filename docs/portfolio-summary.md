# Horizon Dental Studio

**One-line description:** A fictional private dental practice website with a working, database-backed consultation-request flow.

## Project Summary

A calm, responsive site that helps visitors explore treatments, understand indicative fees and request a consultation. Booking requests are validated and stored in Supabase, with optional practice notifications through Resend. Contact is a separate non-persistent demo; requests do not confirm appointments.

## My Role

Product Developer, Frontend Developer and Backend/API Developer, responsible for UX and technical decisions. Independent fictional concept project; no real client relationship is claimed.

## Key Technologies

Next.js 16 · React · TypeScript · Plain CSS · Zod · Supabase PostgreSQL · Resend · Node.js 22

## Key Features

- Treatment discovery and four detailed treatment routes.
- Transparent indicative pricing and practice/team information.
- Clearly fictional patient stories and categorized FAQs.
- Responsive navigation and accessible forms.
- Persistent consultation requests and practice email notifications.
- Safe recovery states, metadata and social previews.

## Technical Highlights

- Shared content and data-driven treatment routes.
- Client/server validation with server-only privileged access.
- Database-first receipt independent of best-effort email delivery.
- Keyboard/focus support, responsive images and native SEO routes.
- Phase 15: 41 passing tests and a successful production build.
