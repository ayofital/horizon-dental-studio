## Dimensions and limitations

Desktop captures used a 1440 × 1000 browser viewport; mobile used 390 × 1000. The browser exports JPEGs and excludes its scrollbar from most captures, so desktop files are 1425px wide. The desktop homepage viewport export is 938px tall. Full-page mobile capture is clipped to 390 × 1200 to include the complete hero; this is a page excerpt, not a simulated phone frame.

Full-page captures are intentionally tall. Use the homepage views for a portfolio card or introduction, and open feature images at full size for readable detail.

Booking success is omitted: no reusable success state was available in the capture session, and no extra live row or email was created solely for an image. The prior [final QA audit](../final-qa-audit.md) provides the live storage/delivery evidence.

No screenshots of provider dashboards, environment files or private configuration are included. Practice content, contact details, names, testimonials and prices visible in the site are fictional examples.
